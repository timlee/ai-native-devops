# Security Policy

## Supported Versions

List the supported versions of this project.

| Version | Supported |
|---|---|
| main | Yes |
| older versions | No |

## Reporting a Vulnerability

Please report suspected security issues privately to the project maintainers.

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Affected version or commit
- Suggested remediation, if known

## Security Expectations

The project should follow these practices:

- Do not commit secrets, tokens, passwords, or private keys
- Validate inputs at trust boundaries
- Use least privilege for service accounts and deployment credentials
- Keep dependencies updated
- Run security scanning before release
- Document security-sensitive design decisions

## AI-Assisted Development Note

AI tools may be used to assist development, but AI-generated code must still be reviewed, tested, and validated before merge.
