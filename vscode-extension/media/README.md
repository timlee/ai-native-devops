## Screenshot Capture Guide

Use these steps on Windows to create the final images:

1. Open the extension in VS Code and switch to the target view.
2. Make sure the window is large enough to show the full panel without cropping important controls.
3. Use the built-in snipping tool or a screenshot shortcut to capture the frame.
4. Save the image as an SVG, PNG, or WebP only if the file stays lightweight.
5. Replace the placeholder files in this folder with the final captures using the same names if possible.
