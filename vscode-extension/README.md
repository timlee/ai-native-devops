# AI-Native DevOps Policy Files

This package contains Markdown policy files for best-practice AI-assisted DevOps governance.

## Contents

- `policies/README.md` — policy directory overview
- `policies/policy-matrix.md` — lifecycle-to-policy mapping
- 23 detailed policy files covering AI, coding, review, testing, security, compliance, deployment, operations, observability, incident response, and exceptions

## Usage

Copy the `policies/` directory into your GitHub repository and link the policies from:

- `README.md`
- `AGENTS.md`
- `CLAUDE.md`
- `CODEX.md`
- `.github/copilot-instructions.md`
- `.github/pull_request_template.md`
- GitHub Actions workflows
