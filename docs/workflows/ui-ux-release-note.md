# UI/UX Release Note

Version: 0.1.8

## Highlights

- Improved the Phase panel with a cleaner header, accessible tab behavior, and clearer requirement cards.
- Added one-click creation for missing required output files from the phase requirements view.
- Improved the Checklist panel with quick actions, section-level progress, and better progress persistence.
- Added a reusable UX information architecture template for design handoff.
- Added GitHub issue draft files and a PowerShell automation script with dry-run and verbose preview modes.

## Validation

- `npm run compile` completed successfully in `vscode-extension`.
- UI changes were validated in the VS Code webview panels.

## Notes
